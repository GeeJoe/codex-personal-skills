# Prompt Templates

Use these as starting structures. Replace bracketed fields and keep the final prompt concise enough for one generation.

## Text-to-Video Viral Short

```text
9:16竖屏，总时长[12/15]秒，[写实/3D卡通/国风/广告]风格。[第一句写3秒钩子：谁在什么地方做了什么意外动作]。

主体：<角色1>，[年龄/气质/服装/发型/关键外观]。
场景：[地点、时间、光线、关键道具、背景氛围]。

0-3s：[景别+运镜]，[角色动作和表情]，[声音/环境音]。
3-7s：[景别+运镜]，[冲突升级或视觉变化]，[台词或音效]。
7-12/15s：[景别+运镜]，[反转/定格/情绪落点]，[结尾台词或BGM处理]。

画质与风格：[高清、电影质感、自然光影、细节清晰、动作连贯]。
约束：不要水印，不要logo，不要无关字幕，不要额外人物，人物脸部稳定，手部自然，无畸形，无闪烁，无低清。
```

## Multimodal Reference Prompt

```text
9:16竖屏，总时长15秒，生成一个[题材]短视频。

素材定义：<角色1> 的面部特征参考图片1，服装和体态参考图片2；场景氛围参考图片3；镜头运动与节奏参考视频1；BGM/音色/情绪参考音频1。请只继承上述指定维度，不要复制无关背景文字、水印或logo。

剧情：前3秒[强钩子]；中段[动作/互动/变化]；结尾[反转/祝福/产品露出/情绪落点]。

分镜：
镜头1：[景别、位置、主体动作、表情、声音]。
镜头2：[景别、运镜、动作承接、台词/音效]。
镜头3：[景别、收尾动作、节奏、BGM/环境音]。

风格：[视觉风格、光线、色彩、质感]。
约束：保持<角色1>身份一致，不生成双胞胎或重复人物，不生成水印/logo，不生成未指定字幕，动作自然连贯。
```

## Strong Reversal Comedy

```text
9:16竖屏，12秒，手持实拍纪实感，[地点]，[普通生活开场]。<角色1>[外观/身份]，一开始很[得意/严肃/自信]。
0-3s：中景，<角色1>[认真做一件看似很帅/很惨/很正经的事]，BGM逐渐变强。
3-7s：镜头快速推近，[突发事件]打断他/她，表情从[自信]变成[尴尬/慌张]，动作要连贯。
7-10s：旁边<角色2>补一句短台词：“[一句反差吐槽]”。
10-12s：<角色1>强装镇定说：“[嘴硬金句]”，BGM戛然而止，现场爆笑。
画质：真实短剧质感，动作丝滑，表情清晰，环境音自然。
约束：无水印，无logo，字幕只在台词处出现，人物不变形，不多生人物。
```

## Blessing / Fortune Direct Address

```text
9:16竖屏，12秒，温暖治愈口播，[室内/庭院/街景]，柔和暖光，轻音乐。
<角色1>穿[干净高级服装]，坐/站在[场景细节]，眼神真诚，对镜头说话。
0-4s：镜头缓慢推近，<角色1>微笑说：“正在看视频的你，先别急着划走。”
4-8s：<角色1>语速放慢，轻声说：“[一句能共情的处境/压力]，都会慢慢变成好运。”
8-12s：<角色1>[举杯/递花/双手合十/抱拳]：“愿你接下来，[三连祝福]。” BGM轻轻收尾。
约束：台词清晰，嘴型自然，中文发音准确，不要多余字幕，不要水印logo，脸部稳定。
```

## Beauty / Dance / Transition

```text
9:16竖屏，12秒，[国风/港风/酷飒/甜妹/敦煌/大漠]视觉大片，BGM卡点。
<角色1>[服装、发型、妆容、气质]，场景为[地点、光线、道具]。
0-3s：全景/中景，[低速入场动作]，镜头缓慢推近。
3-7s：鼓点响起，<角色1>[转身/抬手/甩发/展开飘带/踏步]，服装和发丝随动作自然摆动。
7-10s：卡点转场到[更强场景/更近景别]，动作继续承接，不要跳变。
10-12s：近景定格，<角色1>[眼神/微笑/回眸]，BGM收束。
约束：全身比例自然，手指正常，不崩脸，不多生肢体，不生成水印/logo。
```

## Product / Commercial Clip

```text
[16:9 or 9:16]，[8-12]秒，商业广告质感。[产品]放在[简洁材质表面]，背景[干净场景]。
0-3s：特写，[产品关键材质/水珠/反光/蒸汽]清晰，镜头慢慢推近。
3-7s：镜头[180度环绕/横移/俯拍切特写]，展示[卖点动作]。
7-12s：产品稳定在画面中心，[一句广告语/无文字版本]，灯光扫过边缘。
约束：产品形状和标签稳定，不生成错误文字，不生成无关logo，不生成额外产品，画面干净。
```
